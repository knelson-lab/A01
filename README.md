# A01
OPIM5512 A01 Assignment

The purpose of this assignment is to establish a Git repository with proper introductory description and create access to it online and via GitHub Desktop. It also includes a basic plotting task.  

The data that will be used in that plotting task comes from a California housing dataset. Thie boxplot.py script will load in California housing data and create a box plot of median income and median house value. The final output of this repository and assignment is a boxplot image saved in this directory.

The boxplot.py script can be in any Python IDE or in Google Colab via the !python command if the A01_OPIM5512 repository is mounted to the drive.
